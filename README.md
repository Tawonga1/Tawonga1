### 🌐 Website

This repo also hosts my personal site (`index.html`), deployed via GitHub Pages
through the workflow in `.github/workflows/pages.yml`. Once Pages is enabled
for this repo (Settings → Pages → Source: GitHub Actions), it will be live at
`https://tawonga1.github.io/Tawonga1/`.

To preview locally, just open `index.html` in a browser, or run:

```
python3 -m http.server 8000
```

and visit `http://localhost:8000`.
